# Partner Targets
## Integration Roadmap

### Partner Selection Criteria
- **Revenue Share**: Partners with affiliate or revenue-share programs.
- **Free-Tier Limits**: Partners with generous free-tier limits to minimize costs.
- **Integration Effort**: Partners with straightforward APIs or existing integrations.
- **Value-Add**: Partners that solve specific user jobs.

### Partner Targets
#### 1. GitHub (Integration Effort: M, Value-Add: Code Management)
- **Rationale**: GitHub is a natural fit for code-escrow, with seamless integration for developers to store and manage their code.
- **Free-Tier Limits**: Unlimited public repositories, 2 private repositories.
- **Revenue Share**: GitHub Sponsors (5% commission).
- **Integration Effort**: Moderate ( GitHub API, OAuth).

#### 2. Stripe (Integration Effort: M, Value-Add: Payment Processing)
- **Rationale**: Stripe's payment processing capabilities align with the escrow platform's payment release mechanism.
- **Free-Tier Limits**: $0 monthly fee for up to 1,000 transactions.
- **Revenue Share**: Stripe Affiliate Program (up to 2% commission).
- **Integration Effort**: Moderate (Stripe API, Webhooks).

#### 3. Notion (Integration Effort: S, Value-Add: Project Management)
